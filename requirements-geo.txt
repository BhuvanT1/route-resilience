# ============================================================================
# GEOSPATIAL - GeoTIFF I/O, CRS handling, OSM ground-truth automation.
# Needed only for REAL satellite data. The synthetic demo and the whole
# graph/analytics stack run without any of this.
#
#   pip install -r requirements-geo.txt
#
# GDAL: do NOT `pip install GDAL`. It compiles against a system libgdal and
# fails on most machines. Modern rasterio/fiona wheels bundle their own GDAL,
# so installing rasterio is sufficient and is what this file relies on.
#
# If wheels still fail (common on Windows or older Python), use conda instead:
#   conda create -n rr python=3.11
#   conda install -c conda-forge rasterio geopandas osmnx rioxarray
# ============================================================================
